# Model and rule register

- ecg_cnn_model_card.md: trainable CNN and held-out synthetic evaluation; no real-device inference or clinical accuracy claim.
- baseline_isolation_forest.md: per-user eligibility, random-tree baseline, duration rules and known limits.
- registry.json: machine-readable current artifact status.

Symptom triage uses limited English and Hindi phrase rules and conservative review routing. It has no robust negation/context understanding. Unknown symptoms are never declared safe. General advice is held for the assigned doctor; emergency templates bypass review. No production triage performance is established.

Optional loopback NLP extracts explicitly stated age/duration/severity into a strict schema; users verify suggestions. Report values are deterministically extracted and never generated by an LLM. Original free text and clinician notes are retained without automatic translation.
